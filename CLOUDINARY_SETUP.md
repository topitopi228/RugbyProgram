# Налаштування Cloudinary для динамічного завантаження медіа

## ✅ Що було зроблено

Реалізовано систему динамічного завантаження фото з Cloudinary з розділенням по подіях, що значно підвищує продуктивність сайту.

### Створені файли:
1. **`src/config/cloudinary.ts`** - Конфігурація Cloudinary
2. **`src/pages/MediaPage/cloudinaryService.ts`** - API для завантаження фото
3. **`src/pages/MediaPage/components/EventFilter.tsx`** - UI фільтр подій
4. **Оновлено `src/pages/MediaPage/mediaData.ts`** - Додано категорії подій
5. **Оновлено `src/pages/MediaPage/index.tsx`** - Інтеграція динамічного завантаження

## 📁 Структура папок у Cloudinary

У вашому Cloudinary повинні бути створені наступні папки:

```

├── Lisbon2026/          (Лісабон 2026)

├── britain2026/         (Британія 2026)

```

## ⚙️ Налаштування в Cloudinary

### Крок 1: Увімкнути публічний доступ до списку ресурсів

Для динамічного завантаження потрібно увімкнути публічні JSON списки папок:

1. Зайдіть на https://cloudinary.com/console
2. Перейдіть до **Settings** → **Security**
3. Знайдіть розділ **Resource list**
4. Увімкніть опцію **Enable list resources**
5. Збережіть зміни

### Крок 2: Створити папки та завантажити фото

Для кожної події створіть відповідну папку та завантажте фото:

1. Перейдіть до **Media Library** → **Folders**
2. Створіть папку (наприклад, `Lisbon2026`)
3. Завантажте фото події до цієї папки

**Приклад структури:**
```
Lisbon2026/
├── photo1.jpg
├── photo2.jpg
├── photo3.jpg
└── ...
```

### Крок 3: Генерація публічного списку (опціонально)

Якщо Cloudinary не дозволяє публічний доступ до списку ресурсів через API, можна використати альтернативний підхід:

1. Створіть публічний JSON файл зі списком фото для кожної папки
2. Розмістіть його як статичний ресурс в Cloudinary

## 📊 Переваги нової системи

### 1. **Продуктивність**
- Фото завантажуються динамічно з Cloudinary
- Автоматична оптимізація розміру та формату (`w_1200,q_auto,f_auto`)
- Зменшення розміру сторінки

### 2. **Зручність управління**
- Додавайте нові фото прямо в Cloudinary без зміни коду
- Організація по подіях
- Легке оновлення контенту

### 3. **Фільтрація**
- Користувачі можуть переглядати фото конкретної події
- Красивий UI з інформацією про подію (дата, місце)
- Швидка навігація

## 🎨 Як працює фільтр

Користувач бачить кнопки з подіями:
- **Усі події** - показує всі фото
- **Лісабон 2026** - показує тільки фото з Лісабона
- **Гдиня I (2025)** - показує тільки фото з першого НТЗ у Гдині
- ... і так далі

При кліку на подію:
1. Показуються тільки фото з цієї події
2. Галерея автоматично оновлюється
3. Плеєр показує першу фотку з вибраної події

## 🔄 Оновлення контенту

### Додати нові фото до події:
1. Зайдіть в Cloudinary
2. Відкрийте потрібну папку (наприклад, `Lisbon2026`)
3. Завантажте нові фото
4. Сайт автоматично підтягне їх при наступному завантаженні

### Додати нову подію:

1. Створіть папку в Cloudinary (наприклад, `spain2027`)

2. Додайте подію в `mediaData.ts`:
```typescript
{
    id: 'spain2027',
    folder: 'spain2027',
    name: { UA: 'Іспанія 2027', EN: 'Spain 2027', HUN: 'Spanyolország 2027' },
    date: '10-15 Березня 2027',
    location: { UA: 'Іспанія', EN: 'Spain', HUN: 'Spanyolország' }
}
```

3. Оновіть тип у `mediaData.ts`:
```typescript
export type EventCategory = 
    | 'all'
    | 'lisbon2026'
    | 'spain2027' // нова подія
    | ...
```

4. Додайте папку в `cloudinaryService.ts`:
```typescript
const folders = [
    // ... існуючі папки
    { folder: 'spain2027', eventId: 'spain2027' as EventCategory },
];
```

## 🐛 Усунення несправностей

### Фото не завантажуються?

1. Перевірте, чи правильний `cloudName` у `src/config/cloudinary.ts`
2. Переконайтесь, що папки створені в Cloudinary
3. Перевірте консоль браузера на помилки

### Пусті галереї?

1. Переконайтесь, що фото завантажені в правильні папки
2. Перевірте назви папок (вони чутливі до регістру)

## 📝 Примітки

- Усі фото автоматично оптимізуються Cloudinary (розмір, формат, якість)
- Thumbnails генеруються автоматично розміром 400x300px
- Підтримка всіх форматів зображень (JPG, PNG, WEBP, тощо)
- Можна додавати необмежену кількість фото до кожної події
